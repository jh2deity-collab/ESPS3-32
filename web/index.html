화면을 불러오지 못했습니다

이 콘솔은 웹 서버를 통해 열어야 합니다. index.html 파일을 더블클릭해서 여는 방식(file://)은 브라우저가 자바스크립트 모듈을 막아 동작하지 않습니다.

이렇게 실행하세요 — 프로젝트 폴더에서:

python3 tools/serve.py

# 윈도우
tools\serve.bat          (탐색기에서 더블클릭해도 됩니다)

# 윈도우에 파이썬이 없다면
powershell -ExecutionPolicy Bypass -File tools\serve.ps1

그다음 브라우저에서 http://localhost:8000 을 엽니다.

이미 서버로 열었는데도 이 안내가 보인다면, 브라우저 개발자도구(F12)의 콘솔 탭에 찍힌 오류 메시지를 확인해 주세요. 파일이 일부 빠졌거나 브라우저가 너무 오래된 경우입니다(Chrome/Edge 89 이상 필요).
